# 08 — Glossary

## Domain Terms

| Term | Definition |
|------|------------|
| **Credit** | Virtual currency used to generate videos. 1 credit = 1 video (30 sec) |
| **HPAS** | Hook-Problem-Agitate-Solve — video framework structure |
| **Tier** | User subscription level: free, starter, growth, business, enterprise |
| **Niche** | Content category (e.g., skincare, food, fashion) |
| **Style** | Visual style preset for video generation |
| **Pipeline** | Multi-step content generation workflow |
| **Storyboard** | Scene-by-scene breakdown of a video |
| **Whitelabel** | Custom-branded bot for partner agencies |

## Technical Terms

| Term | Definition |
|------|------------|
| **Circuit Breaker** | Pattern to prevent cascading failures when a provider is down |
| **BullMQ** | Redis-based job queue for async processing |
| **Prisma** | TypeScript ORM for database operations |
| **Fastify** | High-performance HTTP framework for admin dashboard |
| **Telegraf** | Telegram bot framework for Node.js |
| **OmniRoute** | Multi-provider LLM routing service |
| **SSE** | Server-Sent Events for real-time dashboard updates |

## Payment Terms

| Term | Definition |
|------|------------|
| **Midtrans** | Indonesian payment gateway (bank transfer, e-wallet) |
| **Tripay** | Indonesian payment aggregator |
| **DuitKu** | Indonesian payment gateway |
| **NOWPayments** | Crypto payment gateway |
| **Settlement** | Payment confirmed and received |
| **IPN** | Instant Payment Notification (webhook) |
| **VA** | Virtual Account (bank transfer method) |
