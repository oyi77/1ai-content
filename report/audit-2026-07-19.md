# 1ai-content Codebase Audit — 2026-07-19

## Executive Summary

The 1ai-content monolith is a Telegram bot controller + content factory orchestrator + Fastify web frontend, backed by a Python FastAPI media generation engine (port 8767) and a PostgreSQL database via Prisma. The codebase is functionally rich — 507 TS source files (~98K LOC), 62 Python service files (~15K LOC), 150+ API routes, 50+ Telegram commands, 36 Prisma models — and most core content creation workflows (faceless video, carousel, clipping, repurposing) are production-grade. However, structural debt is severe: 25 god files exceeding 500 LOC (5 exceeding 1,100 LOC), test coverage at ~25.4% with large mock-only tests inflating the numerator, 18 dead Python endpoints never called from any consumer, a duplicate FastAPI route pair that would crash on import, 138 bare `throw new Error()` calls with zero error taxonomy, 22 string columns in Prisma that should be enums, pricing duplicated across two runtimes with no sync mechanism, and multiple models/tables with missing indexes or inconsistent relation definitions. The monorepo couples TS and Python loosely with no formal interface contract (no OpenAPI → TS client generation). The report synthesizes findings from 6 parallel scouts.

## Critical Issues (RED)

### C1. `eval()` / `new Function()` in production path (`src/flows/generate.ts`)
A `new Function()` dynamic execution exists in the generate flow. The debt scout noted it was "patched" but **not verified** — no test asserts the patch holds, and no input-sanitization boundary is documented. This is an RCE vector if untrusted input reaches it.

**Fix**: Replace with a safe interpreter or a lookup table. Add a test that proves injection is blocked.

### C2. Duplicate FastAPI routes crash Python API
`/ab-test/{test_id}/start` and `/ab-test/{test_id}/end` are each defined **twice** in `services/api.py` (lines 931 & 965, 942 & 976). FastAPI will crash on import with duplicate operation ID. This means the A/B testing feature is broken at the API level regardless of the feature flag.

**Fix**: Deduplicate the route definitions. Add a lint rule or test that detects duplicate route registrations.

### C3. Payment simulation lacks NODE_ENV gate (`src/routes/payment.ts`)
The payment simulation endpoint can be triggered in production. If `NODE_ENV=production` is set but the simulation path is accidentally hit, it could produce fake confirmations.

**Fix**: Wrap in `if (process.env.NODE_ENV !== 'production')` and add a test.

### C4. Duplicate pricing configuration — two sources of truth
| Source                | Starter Tier          | File                          |
|-----------------------|-----------------------|-------------------------------|
| `src/config/pricing.ts` | IDR 99K / 5+1 credits | `src/config/pricing.ts`       |
| Python `packages.ts`    | IDR 49K / 6 credits   | `services/packages.py`        |

Two sources of truth will cause silent incorrect billing. Not synced automatically.

**Fix**: Single source of truth (TypeScript), export to Python via JSON at build time, or validate they match in CI.

### C5. 18 Python endpoints are dead code
Of ~55 Python endpoints, **18 are never called** from any TypeScript code, EJS template, or cron job:
- `/captions/*` (3 endpoints) — caption system, no caller
- `/engagement/*` (2) — reply system, no caller
- `/download/*` (2) — download endpoints, no caller (uses tikwm cascade)
- `/tikwm/*` (3) — proxy endpoints, no caller
- `/video/*` (5) — processing pipeline, no caller
- `/content/render-ad` (1) — Remotion ad bridge, no caller
- `/carousel/templates/{template_id}` (1) — template detail, no caller
- `/ab-test/{test_id}/start` and `/end` (2) — already duplicates, already dead

These represent ~33% of the Python API surface shipped but unreachable.

**Fix**: Remove or wire each. The `/video/*` and `/captions/*` endpoints represent planned features that were partially implemented — decide whether to complete or delete.

### Duplicate Wrapper Architecture
Two TS service wrappers (`content-factory.service.ts`, `tiktok-automation.service.ts`) both bridge to the same Python API on port 8767. `/remeta` and `/repurpose` are wrapped in BOTH — duplicated code. `POST /regenerate` is a backward-compat alias for `/repurpose` in Python, and `regenCommand` in `tiktok-automation.commands.ts` is just `repurposeCommand` aliased.

### Admin EJS Proxy Gap
6 EJS admin views call Python API via browser-side `PY_API = '/api/py'`. This relies on nginx proxy — `@fastify/http-proxy` is not installed. Dev mode without nginx = 404 for all admin page fetch calls.
